# 多語鍵盤練習 (Multilingual Keyboard Practice)

[![Live](https://img.shields.io/badge/GitHub-Pages-blue)](https://y-cc-k.github.io/Japan/)

英語 (ABC) 與日語 (JIS 假名) 鍵盤練習網站，提供自由探索、挑戰測驗、五十音表、例字與例句朗讀等功能。

## 內容

- `index.html`：主頁（語言選擇）
- `en.html`：英語鍵盤練習（字母發音與位置）
- `ja.html`：日語鍵盤練習（JIS 配列與假名）
- `gojuon.html`：五十音表（母音 × 子音）
- `data.js`：假名與單字資料
- `keyboard-learning-guide.md` / `keyboard-learning-student-sheet.md`：學習指導與練習單

## 使用方式

1. 啟動本機伺服器：雙擊 `start_server.bat`（port 8000）
2. 瀏覽器開啟 http://localhost:8000
3. 或直接開啟 `index.html`

## 功能

- 自由探索 / 挑戰練習模式
- 計分、計時、連對
- 語音朗讀（假名、單字、例句）
- 羅馬拼音顯示
- 出題範圍選擇（全部 / 家長鍵位 / 左手 / 右手 / 自定義）
- JLPT N5–N1 詞彙
- 濁音/拗音、弱點複習
- 深色模式、字體大小調整
- 五十音表（獨立頁面）
