# 日式鍵盤學習 - 假名發音與位置

仿 https://github.com/Y-CC-k/ABC 的鍵盤學習活動，改為日式 JIS 鍵盤與假名（平假名／片假名）練習。

## 使用方式
1. 雙擊 `start_server.bat` 啟動本機伺服器（port 8000），或直接以瀏覽器開啟 `index.html`。
2. 瀏覽器開啟 http://localhost:8000

## 內容
- `index.html`：互動練習網頁（虛擬日式鍵盤、自由探索／挑戰練習、計分、計時、語音）
- `keyboard-learning-guide.md`：學習指導
- `keyboard-learning-student-sheet.md`：學生練習單
- `start_server.bat`：本機伺服器啟動腳本
